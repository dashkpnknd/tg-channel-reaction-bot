# TG Channel Reaction Bot

Управляющий Telegram-бот и фоновый обработчик реакций для собственных аккаунтов из Dialog Hub.

## Работа

- Берёт все включённые аккаунты из базы Dialog Hub. Сессии читает без изменений.
- Запускается на паузе. `/prepare` подключает аккаунты к каналу по одному с интервалом около двух минут, без реакций. Неудачную попытку вступления отмечает как `excluded`; автоматических повторных попыток нет.
- `/launch` подключает аккаунты, начинает с текущего последнего поста и продолжает с новыми постами. Состояние сохраняется после перезапуска службы.
- `/resume` включает реакции только на посты, опубликованные после этой команды. Новые посты находит по истории канала с учётом пропущенных при перезапуске.
- На каждый пост Premium-аккаунт ставит до трёх, а обычный аккаунт одну разрешённую реакцию. Уже поставленные вручную реакции сохраняет.
- `/last5` добавляет последние пять постов в очередь только по явной команде администратора.
- Хранит состояние в SQLite, чтобы не повторять успешно выполненные действия.
- При запросе Telegram подождать аккаунт переводится в состояние `cooldown` без новых попыток; ошибка видна в `/accounts`.
- Поддерживает `/status`, `/accounts`, `/excluded`, `/prepare`, `/launch`, `/pause`, `/resume`, `/last5` в чате администратора.

## Установка

Создать `.env` из `.env.example` и заполнить значения. Секреты и данные в Git не добавлять.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py inspect
sudo cp deploy/tg-channel-reaction-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now tg-channel-reaction-bot
```

`inspect` проверяет канал с одним аккаунтом, не подписывает его и не ставит реакции.
